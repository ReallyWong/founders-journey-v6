# 创业人生 · Founder's Journey

**一款能玩的创业教科书。** 玩家以第一人称经历从辞职创业到上市敲钟（或欠债跑路）的完整旅程，在 30–90 分钟的一局里，浓缩真实创业者 3–8 年会遇到的关键决策。

面向高校就业指导中心、创业孵化器、地方政府创业培训机构设计，可作为创业教育课程的互动教具直接使用。

---

## 为什么是游戏，而不是案例集

案例集告诉你「别人做了什么」，游戏让你**亲手做一遍、并承担后果**：

- 产品、投放、销售三项预算怎么分？——亲手拉动滑块，三个月后看现金流
- 投资人给了「毒丸条款」，签不签？——签了拿到钱，也埋下了被踢出局的伏笔
- 大厂复制了你的产品，跟不跟进烧钱战？——每个选项背后都有真实公司的影子
- 联合创始人要求重新分股权——处理不好，下一局事件就是核心团队出走

每一局结束后，系统会给出复盘报告：你的关键决策、错过的信号、以及对应的「创业课」。

## 三大玩法支柱

| 支柱 | 内容 |
|------|------|
| **创业全流程模拟** | 需求调研 → 用户访谈 → MVP → 种子轮 → 多轮融资 → 上市/并购/关停，30+ 种结局 |
| **真实历史股市** | A 股 / 美股 / 港股，基于真实历史行情（2008 金融危机、2020 疫情等），公司现金可入市投资，股市涨跌与公司事件双向联动 |
| **NPC 对话剧情** | 16 位个性鲜明的 NPC（投资人、合伙人、记者、监管者……）以对话形式推进事件，沉浸感媲美视觉小说 |

## 内容规模

- **10 个城市/地区**：北京、上海、深圳、杭州、香港、东京、新加坡、硅谷、纽约、以色列（部分通过成就解锁）
- **12 个行业赛道**：AI、电商、游戏、智能硬件、生物科技、新能源、金融科技、文化传媒、消费品、传统制造、VC/PE（通关解锁）等，每个行业有专属机制（如智能硬件会被备货占用现金流）
- **6 个历史剧本**：百团大战（2008 团购）、口罩经济（2020）、区块链狂潮（2017）、直播带货（2019）、PC 互联网时代、刀尖起舞（1998），均为固定事件链 + 真实结局改编
- **30+ 结局**：上市敲钟、被并购、破产清算、欠债跑路、被董事会踢出、行业教父、阶下囚……
- **148 个事件**：76% 由具名 NPC 出面推进，灵感来自真实创业史
- **难度分级**：简单（教学）/ 标准 / 真实模式（单次生命、不能读档）

## 内置「创业课」清单（节选）

游戏在关键事件后自动弹出课程卡片，目前已覆盖 30+ 个知识点，包括：

融资条款陷阱（完全棘轮、回购条款、一票否决）、股权分配与成熟机制（vesting）、单位经济模型（LTV/CAC）、烧钱率与 runway、PMF 信号识别、招聘中的履历陷阱、公关危机 24 小时原则、知识产权与竞业、政策合规红线、董事会博弈、上市地选择逻辑……

## 教师使用指南（45 分钟课堂）

1. **讲解（5 分钟）**：介绍本节课主题（如「融资条款」），提示学生关注条款类事件
2. **分组游玩（25 分钟）**：2–3 人一组共用一台设备，轮流做决策——争论本身就是最好的教学
3. **结局复盘（15 分钟）**：每组汇报结局与最关键的一个决策失误，教师对照「创业课」卡片点评

**课堂组织建议**：用比拼码（同码开局、同随机种子）让全班从同一起点出发，比较不同决策路径导致的结局差异，课堂讨论效果最佳。

**机房环境提示**：游戏存档保存在浏览器本地存储，机房还原卡会清除进度。建议单节课内完成（一局约 30–90 分钟），或让学生使用个人设备。

## 本地部署

纯静态站点，无需后端。将构建产物（`dist/` 目录）托管到任意静态服务器即可：

```bash
npm install
npm run build   # 产物在 dist/
```
